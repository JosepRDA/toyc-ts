# toyc-ts 
A simple compiler for the C language written entirely in Typescript. It's designed for a subset of the c programming language that cuts some features, such as specific directives like `__FILE__`. It doesn't support specific features from more mature compilers (e.g. GCC's multitude of flags and checks), but it's simplicity and source code readability is a quality withing it's own.

## Features 
- Compatible with most modern c features 
- Compatible with multiple operating systems (depends on node and npm)
